## How to use

Each framework is written to be picked up and used by someone in an AI transformation seat at a real company. They include the decision logic, the inputs needed, and the outputs produced. They're not theoretical - they're what gets done at 9am on a Monday when a CEO asks "where should we focus this quarter."
