# Tools

Code and scripts that operationalize the frameworks. Things an AI transformation operator can actually run, not just read.

## Planned

- **Workflow scorer**: takes a list of candidate workflows + criteria weights, outputs ranked portfolio
- **Intake bot prototype**: LLM-driven intake form that converts free-form business asks into structured workflow records with dependency extraction
- **Adoption tracker**: simple usage/adoption telemetry pattern for production AI tools

Build language: Python where appropriate, TypeScript for anything browser-side.
